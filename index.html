EXAMPLE — End-to-end detection service

Containerised inference over a public dataset: ingestion, batched GPU inference, and a drift monitor that triggers retraining.

Batching helps throughput and hurts p99 — the queue wait dominates once batch size passes 8.

EXAMPLE — Thin-object detection benchmark

Compared detection, segmentation, and rotated-box pipelines for long diagonal roadside structures.

A diagonal fence's bounding box is over 80% background, so IoU stops measuring what you think it measures.

Segmentation gained +0.14 mAP on high-aspect-ratio instances at 3.2× inference cost — 38 ms/frame against 12.
